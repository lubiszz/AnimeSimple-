# Anime Simple — Versi 1

Aplikasi Android sederhana untuk katalog anime dan daftar episode.

Fitur:
- Beranda
- Pencarian (UI dasar)
- Daftar anime contoh
- Halaman detail anime
- Daftar episode
- Tombol episode yang siap dihubungkan ke video resmi/berlisensi

Catatan:
Versi ini sengaja tidak menyertakan video anime atau link streaming tidak berlisensi.
